# «Омастротривога» для ПК (Windows `.exe`)

Настільна програма для Windows має ті самі можливості, що й Android-додаток:
- **Спільний онлайн-ефір** із телефонами через той самий канал (`omastrotryvoga-kryveozero-live-v1`) та офіційне API тривог України (`ubilling.net.ua`).
- **Комбінування кількох тривог одночасно** (наприклад, *Вуличні бої + Цивільний захист*) та запуск на декілька регіонів одразу.
- **Усі 5 голосових записів** вбудовані всередину `.exe` і звучать по черзі **рівно 1 раз**.
- **Автоматичне збереження** всіх станів, чату, налаштувань та ролі у `%APPDATA%\OmastroTrivoga\state.json`.
- **Права доступу**: повний доступ лише у адміністратора Дениса (PIN за замовчуванням `1234`).

---

## Спосіб 1: Автоматично отримати готовий `.exe` через GitHub (без встановлення програм на ПК)
1. Натисніть **Push to GitHub** у меню AI Studio.
2. Відкрийте вкладку **Actions** у вашому репозиторії на GitHub.
3. Виберіть workflow **Build Windows PC EXE (OmastroTrivoga)** (або натисніть **Run workflow**).
4. Після завершення збірки (~1 хв) завантажте артефакт **`OmastroTrivoga-Windows-EXE`** — усередині буде готовий **`OmastroTrivoga.exe`**.

## Спосіб 2: Зібрати `.exe` в один клік на своєму Windows-ПК
1. Експортуйте проєкт як **ZIP** і розпакуйте на ПК.
2. Відкрийте папку `desktop_pc` і двічі клацніть **`build_exe.bat`**.
3. Скрипт автоматично підготує середовище та створить готовий файл **`desktop_pc\dist\OmastroTrivoga.exe`**.
