# «Омастротривога v2.0» для ПК (Windows `.exe`)

Нова настільна версія для Windows повністю синхронізована з Android-додатком:
- **Вхід через Google акаунт / Firebase Auth** на ПК (з автоматичним відновленням сесії після перезапуску).
- **Синхронізація у реальному часі через Cloud Firestore + резервний ефір (`ntfy.sh`)** з телефонами та іншими ПК.
- **Права доступу за Google акаунтом**: повне керування тривогами лише у підтверджених адміністраторів (`denispekar12@gmail.com` та `semenenkom342@gmail.com`), решта користувачів отримують миттєві сигнали, карту, закріплення до 3 районів та спільний чат.
- **Усі 11 типів тривог**: Повітряна, Ракета/Балістика, БПЛА/Шахеди, Артобстріл, Хімічна, Радіаційна, Вуличні бої, Цивільний захист, Жовтий рівень, Спецсигнал та **окремі кнопки відбою** (включно з **«Відбій цивільного захисту»**) + режим **«Без відбою»**.
- **Усі 12 голосових записів** очищено від подвоєння — кожна загроза і відбій звучить **рівно 1 раз**.
- **Райони України + макс. 3 закріплені райони** на головному екрані з автозбереженням у `%APPDATA%\OmastroTrivoga\state.json`.

## Спосіб 1: Автоматично отримати готові `.apk` та `.exe` через GitHub
1. Натисніть **Push to GitHub** у меню AI Studio.
2. Зачекайте 2–4 хвилини — у репозиторії на GitHub автоматично запустяться збірки:
   - у вкладці **Releases** (справа на сторінці репозиторію) з'явиться реліз **«Омастротривога v2.0.1 (Android APK + Windows EXE)»** з двома файлами:
     - **`OmastroTrivoga-v2.0.1.apk`** — для телефону Android;
     - **`OmastroTrivoga.exe`** — для комп'ютера Windows.
   - або відкрийте вкладку **Actions** → останній запуск **Build Android APK & Windows EXE (OmastroTrivoga)** і завантажте артефакти **`OmastroTrivoga-Android-APK`** та **`OmastroTrivoga-Windows-EXE`**.

## Спосіб 2: Зібрати `.exe` на своєму Windows-ПК
1. Розпакуйте проєкт із GitHub або ZIP.
2. Відкрийте папку `desktop_pc` і двічі клацніть **`build_exe.bat`**.
3. Отримайте готовий файл **`desktop_pc\dist\OmastroTrivoga.exe`**.
